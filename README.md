📊 Global Stock Market Dashboard

An interactive Global Stock Analysis Dashboard built using Streamlit, Plotly, and Pandas.
This dashboard allows users to analyze stock performance across different countries and companies with technical indicators and real-time visual insights

🖥️ Dashboard Overview

The dashboard includes:
📌 Sidebar Filters (Country, Company, Date Range)
📈 Interactive Price Chart (Line / Candlestick)
📊 Volume Analysis Bar Chart
📋 Key Metrics Panel
📍 Automated Market Insight

✨ Key Features
🔎 Smart Filters
Select Country
Select Company
Choose Start & End Date

📈 Advanced Chart Options
Line Chart
Candlestick Chart
Area Chart
Volume Overlay

Highest Price
